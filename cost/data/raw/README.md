# 原始截图采集规范

生活类数据由用户在手机上按清单截图，截图是数据的原始来源。我只负责从图里读数、填 JSON，JSON 里的 `source_url` 指向截图文件。

## 目录

```
cost/data/raw/<city>/<yyyymmdd>/<编号>_<项目>.jpg
```

例：`cost/data/raw/urumqi/20260914/01_eggs10.jpg`。

## 一张合格的截图要看得见的东西

1. **平台名和城市/自提点**（多多买菜顶部的自提点名、美团的定位、贝壳的城市）。
2. **商品名和规格**（10 枚、1L、5kg、500ml×6）。
3. **价格**，含到手价和原价都行。
4. **排序状态**（默认/销量）。同一项截**销量前 3** 的商品，可以在一张图里。

看不见这四样的图我不填，会退回让你补。

# 薪资购买力图 · 数据规范（schema 2）

想法见仓库根 IDEAS.md 第 6 节。这里只定"数据长什么样、什么算合格"。

## 设计原则（2026-09-14 用户定）

**每个数字都要让一个对这座城市一无所知的人也能和别的城市比。** 所以地名不是单位，下面这些才是：

| 维度 | 不这样 | 而是这样 |
|---|---|---|
| 房租 | 按区名 | 按「到市中心枢纽 N 分钟」分档，每档挑几个真实车站当代表 |
| 交通 | 一个"月票" | 每档自己的月票（有人住 1 区有人住 3 区） |
| 岗位 | "饮食业平均时薪" | 全球都有的连锁的**具体门店真实招聘**：7-11、麦当劳、星巴克、亚马逊仓库 |
| 生活费 | 一个总数 | 水电燃气手机宽带各多少（单身用量）；吃饭用巨无霸套餐、星巴克拿铁、鸡蛋牛奶大米这种全球统一的东西 |

平均值混了旧帖导致低于法定最低时薪之类的数字一律不用。

**来源只许官方**（用户严令）：政府统计、法定文件、连锁自己的招聘页和菜单页、运营商官网。招聘聚合站、比价站、新闻转述一律禁止；官网查得到的（岗位时薪、套餐价、定期券）必须去官网查。租房没有官方数据，允许用当地最大的挂牌平台，标 `listing`。

**语言**：简体中文界面下，只有城市名允许带英文（`大阪（Osaka）`），其余文字（标签、说明、来源名、车站名）一律简体中文。

**来源放宽（2026-09-14 用户追加）**：商家自己在公开商品页上标的价（京东自营/天猫超市/美团门店页/连锁官方小程序 H5，不用登录能看到的）算商家挂牌价，标 `listing`。仍禁止的是比价站、新闻转述、众包。
**没有的连锁用本地平替**：便利店任何连锁都行、咖啡用瑞幸/库迪、汉堡用麦当劳/肯德基、仓库用顺丰/京东物流，chain 字段写成"便利店（美宜佳）"并在 note 注明平替。
**中国大陆城市不放签证和留学生打工规则**（用户是中国公民），`work` 只写"中国公民，无工时上限"，页面不算打工上限。

**没有地铁分区或月票的城市怎么分档**：档位只看"公共交通到枢纽的分钟数"，地铁、BRT、公交都算，两条地铁线的城市照样能分；月票没有的城市用官方单程票价 × 44 次做 `estimated` 并在 note 写公式。有分区票价制的城市（大阪地铁 1–5 区）另给 `transit_zones` 表，让人按自己的区找价格。

## 文件

- `cities.json`：城市清单。地图只读这个文件画点：id、三语名、国家、货币、经纬度、`status`（`draft` / `ready`）、`links`。
- `cities/<id>.json`：一个城市一份，点开点才加载，格式见下。
- `rates.json`：汇率与 PPP 因子，带来源和日期。为空时页面只显示当地货币。
- `countries_110m.geojson` / `countries_50m.geojson`：Natural Earth 国界，本地文件。

## 每一个数字的格式

```json
{"value": 1231, "unit": "JPY/h", "source_url": "https://...", "source_name": "7-Eleven 官方招聘网站 大阪市北区",
 "fetched_at": "2026-09-14", "confidence": "listing", "n": null, "note": "北区 55 家店全部 1,231 起", "label": "可选，显示名"}
```

- `value` 为 `null` 表示还没查，页面显示"暂无"。**不许填估计值冒充实测。**
- `confidence`：`official`（官方统计／法定／连锁官方菜单价）、`listing`（招聘或租房平台上的真实挂牌）、`measured`（自己的账目）、`crowd`（众包，只做对照）、`estimated`（推算，note 里写方法）。
- `fetched_at` 必填，超过一年页面标"旧"。

## 城市文件的段落（schema 2）

| 段 | 内容 |
|---|---|
| `hub` | 这座城市的"市中心枢纽"是哪里，档位怎么算 |
| `work[]` | 按签证：上限规则、平台列表 |
| `jobs[]` | 连锁 × 具体门店 × 时薪。固定四个连锁：7-Eleven 便利店、麦当劳、星巴克、亚马逊仓库（中国用京东物流替代并注明）。没有的连锁留 null 并写明（比如缅甸没有星巴克） |
| `wage_ref` | 官方最低时薪（现行、改定预定） |
| `tiers[]` | 四档：`walk`（步行圈 0–5 分）、`t15`、`t25`、`t40`。每档：代表车站、`rent_1k`（单间/1K 月租）、`pass_student`、`pass_commuter`、`fare_single` |
| `utilities` | `electricity` `gas` `water`（官方家计统计，单身）、`mobile`（本地主流 30GB 套餐官方价）、`internet`（公寓光纤官方价）、`comm_official`（统计平均） |
| `basket` | `bigmac_set`、`latte_tall`、`coffee_shop`、`curry_rice`（或本地一顿外食）、`eggs10`、`milk1l`、`rice5kg`、`bread1kg`、`cola1l`、`beer6`。前两个用连锁官方价，其余用官方零售物价统计 |
| `living_official` | 统计平均的食费、消费支出合计，以及本人实测 |

页面现算（不存）：每档「房租 + 水电燃气 + 手机宽带 + 统计食费 + 通学月票」折成**便利店时薪的工时**，再和签证打工上限比。

## 合格线

`ready` 的条件：`jobs` 至少两个连锁有真实门店时薪、`tiers` 至少 walk 和 t25 两档有 `rent_1k` 与 `pass_student`、`utilities` 三项官方、`basket` 至少巨无霸套餐 + 鸡蛋 + 牛奶，全部有 `source_url` 和 `fetched_at`。
